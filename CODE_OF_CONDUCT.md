# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep criticism about the
work, not the person. Harassment and personal attacks are not tolerated in issues, pull
requests, or any other project space.

## Reporting

If someone's behaviour concerns you, contact the maintainer privately through
[GitHub](https://github.com/iezzat001), or use
[Security → Report a vulnerability](https://github.com/iezzat001/AI-teammates/security/advisories/new)
if you need a private channel. Reports are handled confidentially.

The maintainer may remove comments, commits, issues or other contributions that break this
code, and may block people who do so repeatedly, as described in the Contributor Covenant's
enforcement guidelines.
